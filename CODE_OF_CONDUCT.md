# Community conduct

Treat contributors and users with respect. Discuss concrete technical work;
avoid harassment, discrimination, threats, personal attacks and disclosure of
private information. Respect consent and company restrictions when sharing code,
logs, recordings or model transcripts.

Raise conduct concerns privately with the repository owner using an established
private channel. Maintainers may remove abusive content, restrict
participation, or pause discussion to protect participants. Apply these rules
consistently and permit a private explanation or appeal to the owner.

This is an original project policy, not a copied third-party conduct template.
